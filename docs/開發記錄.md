## 3. 上游 CLI 實測行為（20250915，本機）

`-h` 實際輸出的參數：`-n -1/0/1/2/3`、`-s 1/2/4/8/16/32`、`-t >=32/0=auto`、`-m`、`-g`（`-1` 表示 CPU，預設 auto）、`-j`、`-x`、`-f jpg/png/webp`。

| 情境 | exit code | stderr | 程式處理方式 |
|---|---|---|---|
| 正常 2×、4× | 0 | 只有 GPU 資訊行 `[0 NVIDIA ...]` | 驗證輸出檔尺寸是否剛好為 W·s × H·s |
| 模型路徑不含 `models-cunet` | -1 | `unknown model dir type` | 上游以路徑名稱判斷模型類型，所以安裝資料夾名稱必須固定為 `models-cunet` |
| 輸入檔解碼失敗 | **0** | `decode image ... failed` | exit code 不可靠；以「輸出檔存在且尺寸正確」判定成功 |
| GPU 編號不存在 | -1 | `invalid gpu device` | 轉為「找不到可用的 Vulkan GPU」訊息 |
| 中文、日文、空白路徑 | 0 | — | 可正常處理（主控台輸出的路徑會亂碼，不影響處理） |

## 5. A9 實機量測步驟（GTX 1060 6GB，由使用者執行）

準備：一張小圖（約 0.3 MP）和一張接近 4.5 MP 的動漫插畫（例如 3000×1500 或 2100×2100）。先執行 `build.ps1 -Preset release`。

1. 開啟工作管理員的「效能 → GPU」頁籤，觀察「專用 GPU 記憶體」；「詳細資料」頁籤加入「認可大小」欄。
2. 純推論耗時：在 PowerShell 執行下列指令。把 `<in>` 換成圖片路徑，`s` 分別用 2 和 4，`t` 分別用 0（自動）、200、100：
